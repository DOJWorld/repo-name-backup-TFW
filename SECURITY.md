# Security Policy
Report vulnerabilities privately via GitHub "Report a vulnerability" (Security tab) or security@portal.example.invalid. Do not open public issues. Target: acknowledge within 2 working days.

Scope notes: the Netlify site is a static preview with synthetic data. Real data exists only in the AWS eu-west-2 production environment.
No system can be guaranteed unhackable; see docs/operations/ENVIRONMENTS_AND_SECRETS.md for controls and residual risk.
